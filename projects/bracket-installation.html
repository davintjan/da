Force Control and Imitation Learning for Bracket Installation

Compliance control and a learned insertion policy for construction robot arms, reaching a 95% installation success rate.

CompanyRaise Robotics RoleControl Engineer YearSummer 2024 StackPython, PyTorch, ROS

Problem

The project had two parts. First, move the force and compliance controller from the UR20 arms to the FR20 arms with the same performance. Second, learn a model that inserts brackets automatically from a start pose and an estimated goal pose. The perception system that estimates the goal has errors of up to ±2° in orientation plus some translation error, so the model has to compensate for them.

Approach

  • Compliance and force control for contact tasks such as channel search, bracket alignment and nut tightening and loosening.
  • A behavior-tree state machine for smooth, deterministic transitions between steps.
  • An imitation learning model in PyTorch, trained on data from an automated collection pipeline.
  • Hardware setup: launch files, URDF, controller gains, and mounts for the force-torque sensor, pneumatics and tool changer.

Result

After tuning stiffness, PD and error-scale gains, bracket installation reached a 95% success rate. The learned insertion model matched expert trajectories with a position and orientation RMSE below 0.0001.
